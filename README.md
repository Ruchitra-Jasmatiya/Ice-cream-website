# About the Project

**FreshnFreeze** is a visually immersive ice cream website designed to deliver a delightful digital dessert experience. The project combines elegant UI design, smooth micro-interactions, and responsive layouts to create a premium landing page for an artisan ice cream brand.

Every section is carefully animated using **Framer Motion**, styled with **Tailwind CSS**, and built with **React** to ensure a fast, engaging, and modern user experience.
